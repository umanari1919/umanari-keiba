# NEO JIZO ATLAS — 安全な改称・移行方針

## 目的

旧研究ブランドTHE JOCKEYを **NEO JIZO ATLAS** へ改称し、NEO JIZO FORWARD（予測と実戦検証）、THE JOCKEY（ゲーム）との境界を明確化する。

## 第1段階：人が読む名前（このPR）

- READMEとプロジェクト構成資料に新名称を記載する。
- 過去の履歴、既存文書、プログラム内の識別子は変更しない。
- 研究がATLAS、予測運用がFORWARD、ゲームがTHE JOCKEYという基準を設ける。

## 第2段階：表示UIの改称（別PR）

研究ダッシュボードにATLAS、レース予測画面にFORWARDを表示する。既存画面やAPIの動作確認をしてから対象ファイルだけを変更する。ゲームUIは実装段階になってから名称を採用する。

## 第3段階：技術移行（別途の明確な承認後のみ）

必要な場合にだけGitHubリポジトリ名・フォルダー・モジュールの再編を検討する。その際は以下を先に検証する。

- GitHub Actions、CI、固定コミット付きraw URL、PowerShellランナー
- ローカルGit remote、Python import、既存自動化と固定パス
- JRA/NAR予測の証拠・データソース・ライセンス
- PostgreSQL、馬王Z、ローカルデータとの非破壊互換性
- リンク切れ検査とロールバック手順

**今回実施しないこと：** リポジトリ改名、フォルダー移動、歴史的コミットの書換え、DB移動・削除・初期化、サービス起動停止、ゲーム実装の完了宣言。

## ATLASからFORWARDへの移行条件

ATLASでの履歴評価PASSだけでは本番予測を承認しない。FORWARDでは正しい出馬表、発走前の予測時刻と不変ハッシュ、結果後の照合、出走馬IDの一致、結果欠損の隔離、3目標性能・校正の確認が必要。

2026-10-08時点のCORE-010オフライン評価は歴史的な参考診断であり、将来レースの事前凍結予測を代替しない。
