# NEO JIZO ATLAS — UI-001 表示責務の分離

日付：2026-10-08  
状態：Pull Request提案中（本番画面の更新完了を意味しない）

## 目的

ATLAS（研究）とFORWARD（レース前予測・実戦検証）の画面名を明確に分離し、過去のTHE JOCKEY研究表示から段階移行する。

## 変更範囲

- `tools/research_dashboard/dashboard_server.py`：研究ダッシュボードのウィンドウ名・見出し・起動メッセージをATLASへ。
- `src/publish_weekend_ui.py`：個人向け週末予想・再現予想パネルの見出しをFORWARDへ。予測の判定・時刻・予想データには変更なし。
- `web/index.html`：共通ヘッダーはJIZO WORKS、研究セクションはATLAS、週末予想セクションはFORWARDへ。
- `tests/test_atlas_branding.py`：画面の名称境界と重要な既存要素の維持を回帰テスト化。
- `.github/workflows/neo-jizo-atlas-ui-001.yml`：上記コードに対する独立・軽量の品質ゲート。

## 変更しない範囲

- jockey-25のモデル、1着・2着以内・3着以内の確率、調教候補の採否。
- 出走表取得、時系列制約、結果照合、予測の凍結方法。
- DB / PostgreSQL / WSL、既存の研究・ゲーム・馬王Z資産。
- GitHubリポジトリ名、技術識別子、過去のGit履歴。
- 自動投票・本番モデル昇格・商用化判断。

## 検証

- 文字列置換は既存ファイル内の各対象箇所がちょうど一箇所である場合のみ実施。
- Python構文検査、名称の回帰テスト、および既存の週末予想CIをPRで確認する。
- 実際のブラウザー表示とローカルデータ連携は、このGitHub-only変更では未検証。
