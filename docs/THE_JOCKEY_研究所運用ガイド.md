# THE JOCKEY 研究所運用ガイド

## 目的
THE JOCKEYは、単なる競馬予想プログラムではなく、データ取得・能力評価・確率予測・馬券戦略・独立監査・失敗分析を分離して継続研究する自律型競馬研究所です。

## 基本原則
1. 能力評価と市場オッズを混ぜない。
2. 研究層・予測層・意思決定層・独立監査層を分離する。
3. TEST/OOS/Forward Blindの役割を混同しない。
4. 1回の外れでルールを変更しない。
5. 自動購入・資金移動は行わない。
6. データ異常・漏洩・資源逼迫時は研究速度より安全を優先する。

## 研究所の4層
### 1. 研究層
- データ棚卸し
- 未利用データ統合
- 特徴量研究
- 時系列最適化
- Universal / JRA / NAR / Ensemble
- 継続実験・仮説生成

### 2. 予測層
- P(Win)
- P(Top2)
- P(Top3)
- 着順分布
- Race Simulation
- WIN / WIDE / QUINELLA / EXACTA / FRAME / TRIO / TRIFECTA の成立確率
- Fair Odds

### 3. 意思決定層
市場オッズはこの層でのみ参照します。
- Edge
- EV
- MIN-1 / MIN-2 / MIN-3
- JRA午前資金形成仮説
- NAR Opportunity Driven戦略

### 4. 独立監査層
- OOS
- Forward Blind
- Failure Analysis
- 将来のBlind Betting

## 日常運用で最初に見る場所
ダッシュボード上段の「今日の状態」を確認します。
- 研究所総合状態
- 本番ゲート
- 資源状態
- 漏洩監査
- 自律運転

正常なら研究を継続します。Schema/LeakageがBLOCKEDなら、研究結果を採用しません。

## 人間が判断する場面
Founder判断が必要なのは、原則として以下です。
- 法的・権利上の判断
- 不可逆なデータ削除
- 本番運用方針の重大変更
- 資金移動・実購入
- 研究所の基本方針変更

それ以外は可能な限り自動化します。
